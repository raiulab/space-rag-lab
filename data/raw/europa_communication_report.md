# 評価範囲

本書はRAG教材用の架空評価書である。木星の衛星エウロパを周回する無人探査機について、長い通信遅延と放射線による計算機エラーへの対策を扱う。

# 通信遅延への対策

試験シナリオでは地球までの片道通信時間を33分から53分と設定した。地上からリアルタイム操作できないため、探査機は観測計画を12時間分保存し、結果をいったん機内に蓄積してからまとめて送信する。緊急時も地上応答を待たず、安全モードへ自律移行する。

<!-- page: 2 -->
# 放射線試験

30日間の模擬試験で、主計算機のビット反転を3回検出した。三重化した計算結果の多数決を使うTMR方式では、3回とも誤った値を出力せずに処理を継続できた。異常を検出した計算機は再起動し、正常な2系統から状態を復元した。

# 通信回線

通常の科学データには高利得アンテナを用いる。姿勢異常時は低利得アンテナへ切り替え、データ量を減らした生存信号を30分ごとに送る。未送信データは時刻と優先度を付けたキューで管理する。

# 推奨事項

通信遅延には自律運用と蓄積転送で対応し、放射線エラーにはTMRと再起動を組み合わせる。次段階では同時に2系統が故障するケースを追加する。本書は教材であり、実機の設計認証には使用できない。
