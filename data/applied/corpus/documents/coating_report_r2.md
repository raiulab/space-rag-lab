# 改訂概要

本書はRAG実習用の架空データであり、第1版の500時間試験を750時間まで延長した結果を追加する。硬化条件と端部前処理も変更した。

# 試験対象

新たなアルミニウム試験片B-201からB-212までの12枚を使用した。第1版の試験片とは別ロットであるため、結果を単純に連結しない。

<!-- page: 2 -->
# 更新した成膜条件

端部を二段階で洗浄し、硬化条件を165 ℃、35分へ変更した。乾燥後の平均膜厚は44 µm、標準偏差は2 µmだった。膜厚計TH-08は試験前に校正した。

# 初期検査

試験前の密着性は全12枚で5Bだった。目視検査で剥離、膨れ、割れは確認されなかった。

<!-- page: 3 -->
# 長時間試験

塩水噴霧500時間では全12枚が密着性4B以上だった。750時間後は9枚が4B、3枚が3Bで、端部に小さな膨れを認めた。基材中央部の腐食は確認されなかった。

| 指標 | 500時間 | 750時間 |
| --- | ---: | ---: |
| 4B以上の試験片 | 12枚 | 9枚 |
| 3Bの試験片 | 0枚 | 3枚 |

<!-- page: 4 -->
# 高湿度保管と結論

温度40 ℃、相対湿度90 %で14日間保管した別の確認片4枚には、剥離を認めなかった。今回の条件では165 ℃、35分硬化を次段階の候補とするが、量産採用は決定していない。

# 版の扱い

第2版は第1版を置き換えるが、第1版の観測値を削除しない。比較時は試験片ロットと試験時間の違いを表示する。
