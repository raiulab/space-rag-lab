# Space RAG Lab v0.1.1

公開日: 2026-10-09

v0.1.1は、v0.1.0のLab 1〜3学習体験を変えず、Publicリポジトリと任意APIの安全性を強化するメンテナンスリリースです。APIキーなしのコア経路と評価値を維持しています。

## 主な変更

- GitHub Actionsを検証済みcommit SHAへ固定
- Python 3.10〜3.12のテストに加え、`pip-audit`による依存監査を追加
- CodeQLによるPythonコードスキャンを追加
- DependabotでpipとGitHub Actionsを月次確認
- Lambdaの質問長を2〜500文字へ制限
- Lambdaの内部例外メッセージを利用者へ返さないよう修正
- ローカルAPIとPDF解析の既知のセキュリティ境界を明記

## 維持する動作

- Lab 1〜3のローカル学習UI
- APIキー不要の文書加工、検索、抽出式RAG、評価
- 文字レイヤー付きPDFの25 MB・200ページ上限
- retrieval 1.00、citation 0.80、keyword 0.95、answerability 0.80の基準値

## 既知の制約

- FastAPIとAWSサンプルは認証・認可・レート制限を備えた本番APIではありません。
- PDF解析は別プロセスやOS sandboxへ隔離していません。出所を信頼できないPDFを処理しないでください。
- `rag-lab all`は同じcheckoutで並行実行せず、完了後に`rag-lab ask`などを実行してください。
- Lab 4〜8のローカル学習UI、OCR、表・図・一般画像解析は未実装です。

## 更新

```bash
git pull --ff-only
source .venv/bin/activate
python -m pip install -e '.[ui,pdf]'
python -m unittest discover -s tests -v
rag-lab all
```
