# 文書の位置づけ

この報告書はRAG実習用に作成した架空データである。数値や組織名は教材上の仮定であり、実在する宇宙計画の仕様ではない。

# 試験目的

月面南極域で使う架空の観測装置「LUNA-SCOPE」の熱設計を比較した。真空槽で昼間条件と夜間条件を再現し、放熱塗装と多層断熱材の効果を確認した。電子機器の許容上限温度は85 ℃、夜間の許容下限温度はマイナス35 ℃とした。

<!-- page: 2 -->
# 昼間条件の結果

放熱塗装Aを使った試作機の最高温度は78 ℃だった。放熱塗装Bでは最高温度が92 ℃となり、許容上限の85 ℃を7 ℃超えた。このため昼間運用には放熱塗装Aを採用する。

# 夜間条件の結果

多層断熱材を追加すると、装置を許容温度内に保つためのヒーター消費電力が20 Wから16 Wへ減った。削減率は20 %である。夜間は温度センサーを10分ごとに監視し、マイナス30 ℃を下回った場合に予備ヒーターを起動する。

<!-- page: 3 -->
# 結論と残課題

推奨構成は放熱塗装Aと多層断熱材の組み合わせである。次の試験では月の砂を模した粉体が表面に付着した場合の放熱性能を評価する。乗員数や有人基地の居住設備は本試験の対象外であり、本文書には記載していない。
