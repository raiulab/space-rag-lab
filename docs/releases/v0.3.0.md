# Space RAG Lab v0.3.0

公開日: 2026-10-09

v0.3.0は、Lab 4・6・7・8の学習画面を追加し、APIキーなしで基礎編のLab 1〜8を一続きに学べるようにする機能リリースです。外部LLMとAWSは任意の発展経路であり、既定の学習経路はネットワークや認証情報を必要としません。

## 主な変更

- 同じ検索根拠で抽出式生成と外部LLMを比較するLab 4 UI
- AWSなしで成功、スロットリング、タイムアウト、モデル設定不正を試す模擬API
- Bedrock実行前の料金・データ送信確認と、保存情報を絞った学習記録
- 同じ10問で設定を1項目だけ変え、4指標と新規失敗を比較するLab 6 UI
- v1・v2・v3案の根拠、引用、拒否、文書内命令、JSON契約を検査するLab 7 UI
- 既存プロンプトを上書きしないv3案のローカル保存
- SAM設定とLambda相当のHTTP入出力をローカル点検するLab 8 UI
- IAM最小権限、料金監視、削除手順を考えるデプロイ前学習記録

## オフラインで利用できる範囲

- Lab 1: Markdown、TXT、文字レイヤー付きPDFの加工
- Lab 2: dense、BM25、hybrid検索の比較
- Lab 3: 検索、抽出式回答、引用、回答可能性
- Lab 4: 外部LLM連携の模擬成功・失敗と抽出式生成との比較
- Lab 5: 検索、1文書要約、質問応答の比較
- Lab 6: 同一評価セットによる変更前後の精度比較
- Lab 7: プロンプト契約とJSONL出力例の構造検査
- Lab 8: SAMテンプレートとLambda相当処理のデプロイ前確認
- 評価診断: 失敗分類、変更前後比較、段階的ヒント、学習レポート

## 評価基準値

- retrieval hit rate: 1.00
- citation hit rate: 0.80
- keyword recall: 0.95
- answerability accuracy: 0.80

回答不能問題の誤判定など、再現可能な既知の失敗はLab 6・7の教材として維持しています。

## 安全性と外部サービス

- APIキーやAWS認証情報を作成・保存しません。
- Lab 4のBedrock実行は、料金とデータ送信を明示確認した場合だけ有効になります。
- 学習記録には回答本文、チャンク本文、モデルID、認証情報、外部APIの例外詳細を保存しません。
- Lab 8の完了はローカルのデプロイ前準備を意味し、AWSへの配置済みを意味しません。
- 公開リポジトリではCI、依存関係監査、CodeQL、Secret scanning、push protectionを使用します。

## 既知の制約

- FastAPIとAWSサンプルは認証・認可・レート制限を備えた本番APIではありません。
- AWS SAMの実デプロイは検証していません。
- PDF解析は別プロセスやOS sandboxへ隔離していません。出所を信頼できないPDFを処理しないでください。
- OCR、表構造、図、一般画像解析は未実装です。
- HashEmbeddingと抽出式生成器は学習用ベースラインです。
- Lab 7の静的検査は、実際のLLMがプロンプトへ従うことを保証しません。
