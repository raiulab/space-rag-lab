# Space RAG Lab v0.2.0

公開日: 2026-10-09

v0.2.0は、評価結果を読んで次の実験を決めるMilestone 3と、検索・要約・質問応答を比較するLab 5を追加した学習機能リリースです。APIキーなしのコア経路と、v0.1.1で追加した公開リポジトリのセキュリティ設定を維持しています。

## 主な変更

- 評価JSONの4指標と失敗問題を表示する「診断・比較」画面
- 検索、引用、回答内容、回答可能性の4分類
- 観察、原因の切り分け、次の操作を順に示す3段階ヒント
- 同じ問題ID集合を使った変更前後の指標差分、改善問題、新規失敗の比較
- 回答・チャンク本文を複製しないMarkdown学習レポート
- 検索、1文書要約、質問応答の違いを比較するLab 5 UI
- 付属データとLab 1で保存したデータセットの再利用
- Lab 5の予想、観察、完了条件、ローカル進捗保存

## オフラインで利用できる範囲

- Lab 1: Markdown、TXT、文字レイヤー付きPDFの加工
- Lab 2: dense、BM25、hybrid検索の比較
- Lab 3: 検索、抽出式回答、引用、回答可能性
- Lab 5: 検索、1文書要約、質問応答の比較
- Milestone 3: 評価診断、変更前後比較、段階的ヒント、学習レポート

## 評価基準値

- retrieval hit rate: 1.00
- citation hit rate: 0.80
- keyword recall: 0.95
- answerability accuracy: 0.80

既知の失敗を教材として維持しています。平均値だけでなく、「診断・比較」画面で失敗問題と副作用を確認してください。

## 既知の制約

- Lab 4・6〜8にはガイド、CLI、一部基盤がありますが、Lab 1〜3・5と同じ操作画面は未実装です。
- FastAPIとAWSサンプルは認証・認可・レート制限を備えた本番APIではありません。
- PDF解析は別プロセスやOS sandboxへ隔離していません。出所を信頼できないPDFを処理しないでください。
- OCR、表構造、図、一般画像解析は未実装です。
- HashEmbeddingは学習用の再現可能な基準器であり、本格的な意味Embeddingモデルではありません。
