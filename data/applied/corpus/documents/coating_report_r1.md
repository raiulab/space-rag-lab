# 文書の目的

本書はRAG実習用に作成した架空の研究報告書である。実在の組織、製品、人物、研究成果とは関係がなく、記載値を実製品の設計や安全判断に使用してはならない。

# 試験対象

アルミニウム試験片へ保護膜C-17を塗布し、塩水噴霧環境での外観、膜厚、密着性を確認した。試験片はA-101からA-112までの12枚である。

<!-- page: 2 -->
# 成膜条件

第1版では、前処理後の試験片を160 ℃で30分硬化した。乾燥後の平均膜厚は42 µm、標準偏差は3 µmだった。測定には架空の膜厚計TH-08を使用した。

# 初期検査

試験前の密着性は全12枚で5Bだった。目視検査では剥離、膨れ、割れを認めなかった。

<!-- page: 3 -->
# 500時間試験

塩水噴霧500時間後、12枚中10枚は密着性4Bを維持した。残る2枚は端部に小さな膨れがあり、密着性は3Bだった。基材中央部の腐食は確認されなかった。

| 指標 | 試験前 | 500時間後 |
| --- | ---: | ---: |
| 密着性中央値 | 5B | 4B |
| 膨れを認めた試験片 | 0枚 | 2枚 |

<!-- page: 4 -->
# 暫定結論

C-17は500時間まで概ね良好だったが、端部の前処理に改善余地がある。量産条件の決定前に750時間試験と高湿度保管試験を追加する。

# 適用範囲

本結果は今回の合成試験条件だけを対象とする。屋外寿命、人体への安全性、海洋設備への適合性は評価していない。
