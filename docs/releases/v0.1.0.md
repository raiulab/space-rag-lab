# Space RAG Lab v0.1.0

公開日: 2026-10-04

v0.1.0は、RAGの文書加工、検索、根拠付き回答をAPIキーなしで学べる最初の公開版です。付属の架空データに加え、自分の文字レイヤー付きPDFでもLab 1〜3を実行できます。

## この版で完成している学習経路

1. Lab 1でMarkdown/TXTまたはPDFをページと出典を保ったチャンクへ変換する。
2. Lab 2でdense、BM25、hybrid検索を同じ条件で比較する。
3. Lab 3で検索結果から抽出式回答と引用を生成し、根拠へ戻れるか確認する。

すべてローカルで動作し、APIキー、AWSアカウント、ネットワーク接続は不要です。

## インストール

```bash
cd space-rag-lab
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[ui,pdf]'
python -m unittest discover -s tests -v
rag-lab all
rag-lab ui
```

Windowsでは`.venv\Scripts\activate`で仮想環境を有効化します。

## 対応範囲

- Python 3.10〜3.12
- Windows、macOS、Linux
- 付属Markdown/TXT
- 暗号化されていない文字レイヤー付きPDF 1件、25 MB・200ページまで
- ローカルStreamlit UIのLab 1〜3

## この版に含まれないもの

- Lab 4〜8の学習UI
- スキャンPDFのOCR、表構造、図、一般画像の意味解析
- 本番向けEmbeddingモデルまたは既定の外部LLM
- AWSへの実デプロイ保証
- マルチユーザー向けホスティング

Lab 4〜8にはガイド、CLI、一部のAPI・Bedrock・AWS基盤がありますが、Lab 1〜3と同じナビゲーション体験にはまだなっていません。

## 公開前のローカル検証

- 標準ライブラリ中心のコア環境
- UI/PDF extraを含む全単体テスト
- `rag-lab all`のオフライン評価
- `rag-lab ask`の代表質問
- 依存なしのクリーン仮想環境からのインストール

検証結果と既知制約は`docs/PROJECT_HANDOFF.md`および`CHANGELOG.md`を参照してください。
