# 対象範囲

本書は教材用の架空月報であり、清浄室CR-2の温度、相対湿度、粒子数をまとめる。実在施設の環境記録ではない。

# 管理範囲

温度は21 ℃から24 ℃、相対湿度は40 %から60 %を管理範囲とする。0.5 µm以上の粒子数は1立方メートルあたり3,520個以下を日常管理値とする。

<!-- page: 2 -->
# 週別集計

| 週 | 平均温度 | 平均相対湿度 | 最大粒子数 /m³ |
| --- | ---: | ---: | ---: |
| 第1週 | 22.1 ℃ | 48 % | 1,840 |
| 第2週 | 22.4 ℃ | 51 % | 2,110 |
| 第3週 | 23.0 ℃ | 63 % | 2,480 |
| 第4週 | 22.3 ℃ | 50 % | 1,920 |

第3週の平均相対湿度は管理上限を3ポイント超えた。粒子数は全週で日常管理値以下だった。

<!-- page: 3 -->
# 第3週の確認

湿度上昇は6月18日09時から13時に集中し、最大値は66 %だった。同時間帯に空調系統AC-2の除湿運転が停止していた。試料への影響はこの月報だけでは判定していない。

# 対応

AC-2を再起動し、湿度が60 %以下へ戻ったことを確認した。影響を受けた可能性のある作業は別の品質記録で評価する。

<!-- page: 4 -->
# 結論

温度と粒子数は月間を通して管理範囲内だった。相対湿度は第3週に逸脱したため、空調停止アラームの通知先を環境管理グループにも追加する。

# 注意

月平均だけでは短時間の逸脱を隠すことがある。質問回答では週別表と時刻別確認の両方を根拠として示す。
